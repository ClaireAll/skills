## 通用横切维度

**几乎每个需求都要对照**,按本期实际涉及的对象挑。
权威来源:通用场景 wiki `https://fanruan-x.feishu.cn/wiki/VrWkwS6Jvi5CkZkEwxWcS3WLnKf`

把下面映射成脑图叶子(集中挂「通用横切 / 交叉场景」,或拆到各功能模块下,二选一但不得整段缺席):

- **名称很长**:空间名 / 项目名 / 文件名 / 表名 / 字段名等
- **数量很多**:字段很多 / 文件很多等
- **字段类型是否覆盖全**:文本 / 数值 / 高精度数值 / 日期 / 年月日时分秒 / 复合字段 / 融合版系统字段
- **字段数据**:空值 / null / 异常值 / 文本含换行
- **搜索**:无搜索内容等
- **项目**:过期项目 / 跨项目使用
- **依赖资源丢失或类型改变**:字段丢失 / 表丢失 / 字段类型改变

与本期明显无关的维度,在第 5 节或对话标「本期不适用:…」,别机械堆砌。

## 公式类需求

**启用条件**:涉及公式编辑 / 计算字段 / DEF / 快捷计算 / 聚合或合计公式 / 条件样式中的公式 / 函数及其参数与类型限制 任一。明确「本期无公式」就跳过并注明。
权威来源:公式相关 wiki `https://fanruan-x.feishu.cn/wiki/D1T7wDqaYiPutkk7VyRc9stynqb`

最低对照集(挂「公式 / 计算 / 校验」或对应功能模块下):

- **null 字面量**:公式框直接输 `null`;注意**不同入口规则可能不同**(交叉表合计行-计算值等处是否允许,与通用公式框对比)
- **取反**:`!字段` 等写法
- **比较与逻辑符号**:`>` `<` `=` `&` `%` `<=` `&&` 的识别与校验
- **空字符串**:是否支持 `""`
- **前导正负号**:公式前直接 `+` / `-`
- **布尔字面量**:`true` / `false`
- **括号嵌套**:本不合法的表达式,多层 `()` 嵌套是否被**误判为合法**
- **计算字段链式 / 嵌套四则**:被引用计算字段是否作为**一个整体**参与后续运算
- **同字段多次出现**:非法组合下的校验与提示
- **跨公式复制粘贴**
- **数值型函数参数类型**:限制为数值时,非数值字段前加 `+` / `++`
- **数值函数与四则组合**后的合法性
- **函数参数支持**:尤其**列表、文本类参数**与函数声明的匹配

不同入口对同一写法支持不一致时,用脑图节点区分入口,必要时标 `【待确认】`。

## 分析组件类需求

**启用条件**:涉及分析组件 / 交叉表 / 行列维度字段框 / 指标字段框 / KPI 指标卡 / 分析表样式 / 计算逻辑 / 分析表导出(图片或数据)/ 飞书卡片 / 钉钉酷应用群吊顶 / 表内表间结果传递 / 字段标红 任一。明确「本期不涉及分析组件」就跳过并注明。
权威来源:分析组件 wiki `https://fanruan-x.feishu.cn/wiki/WogRw2xgKixfFrkgLNAcXQRUnke`

**统一挂脑图一级节点「分析组件交叉场景」**(勿用「分析组件专项」等别称):

- **交叉表字段框组合**(七种,逐项覆盖,不得漏组合):仅行维度 / 仅列维度 / 仅指标 / 行+列 / 行+指标 / 列+指标 / 行+列+指标 都有字段
- **样式变动** → 须覆盖**导出图片**
- **计算逻辑变动** → 须覆盖**导出数据**、**飞书卡片**
- **KPI 指标卡** → 须覆盖**钉钉酷应用群吊顶**
- **字段名传递**:表内结果传递(改前序步骤)、表间结果传递(改父表步骤)
- **字段异常标红**:字段类型改变、字段丢失

## 导出类需求

**启用条件**:涉及数据 / 图片 / PDF 导出、导出按钮与权限、安全管理-导出控制、版本导出行数或次数限制、公开分享 / 公共链接导出、仪表板或故事板导出、联动 / 筛选 / 钻取后导出、多分页导出、未加载组件导出 任一。明确「本期不涉及导出」就跳过并注明。
权威来源:导出 wiki `https://fanruan-x.feishu.cn/wiki/DtiNwWSnti4Ctak9f4XcEtFBndd`

**统一挂脑图一级节点「导出交叉场景」**(勿用「导出专项」等别称):

- **安全管理-导出控制**:有导出权限的用户可导出;无权限用户导出按钮**灰化**不可点
- **版本内导出行数 / 次数**:受版本导出数据量(如 1w 行)及次数限制影响
- **公共链接上的导出按钮**:
  - **登录态**才展示:用户**在当前企业内**→可正常导出;**不在企业内**→不可导出并有明确提示
  - **非登录态**:不展示导出按钮
  - **权限动态回收**:打开时曾有导出权限,管理员随后回收,用户再点导出的行为与提示
- **仪表板内导出**:联动后 / 筛选后 / 钻取后 / 多分页 / 未加载完成的组件
- **导出 PDF**:仪表板或故事板**内容很长** / 存在**未加载**内容 / 存在**报错**内容

公共链接导出须区分登录 / 企业内外 / 权限回收;仪表板导出须区分联动 / 筛选 / 钻取 / 分页 / 未加载,**别合并成一条「导出正常」**。
