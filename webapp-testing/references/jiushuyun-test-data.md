# 数据准备与接口返回模拟

来源及具体操作截图见 [测试百宝箱索引](toolbox-sources.md)。以下方法只有在本次任务确实需要且获授权时执行；读到操作手册不等于获准修改环境。

## 接口返回构造

原文给出 Chrome Network“替换内容”和 Fiddler 规则返回。自动化时可用已有 Playwright 路由完成同一目的，不要求安装抓包工具、证书或浏览器扩展。

1. 先观察实际 URL、方法、请求体和返回契约。尤其分页/搜索接口，同一路径可能有不同请求体；成员录屏按方法、URL、企业 ID 与页码分别匹配。
2. 对本场景、本上下文安装最小匹配范围的临时拦截，再触发页面请求。不要一条通配规则替换整个域名，也不要把只读回包测试变成向真实后端提交构造数据。
3. 只改变被测试的字段，保留契约需要的 success/code/data 等包裹结构。分别识别 HTTP 失败、HTTP 200 的业务失败、空列表/缺字段和延迟；预期 UI 由当前需求确定。
4. 记录命中的请求及注入内容，确认页面确实使用了替换后的响应。没有命中不能记场景通过。
5. 清除本次路由、Overrides 或代理规则，重新触发实际请求确认恢复。报告中明确“模拟回包分支”，不把它记为真实后端故障或真实权限校验通过。

源文中的网盘安装包、购买渠道和旧版截图不是 Skill 的依赖安装要求。

## 数据源选取

覆盖范围由本次需求决定，不能机械地每个任务都测试全部连接。

- Excel/自定义表格、简道云/系统数据、云数据库、本地数据源、API 等自有数据源各有差异；跨数据源能力变更应分别考虑适用类型。
- 公共数据源（节假日、行政区域等）文档说明无需授权，可按适用范围选代表；DM 应用数据源可选代表，标记 Alpha 的类型单独考虑。
- 简道云支持账号/密钥授权，但不把文档里的测试/生产密钥复制到脚本或仓库。环境、授权企业和实际可见数据需当次核实。
- 企业项目表被标为旧版本移除、资产监控被标为某版本新增等，属于版本线索，不当作永久产品规则。
- 源文中“这个好用、其他不确定”是作者经验，不代表当前连接成功；先做实际只读连接验证。缺公共数据时记录需准备的样本，不擅自加入他人企业。
- 本地宝：确认服务器、容器/实例、访问端口、绑定企业和用途备注；读取备注中的“不可删除”等限制。共享环境有实例数量/负载约束，优先复用指定实例。
- 文档说明 A/A+2000/A+4000 端口映射与独立 Excel 服务；检查当前实例真实地址和服务状态，不从映射公式推导后就直接写文件。
- Excel 服务可增删改远端文件，配置、JAR、重启/停止/删除容器也都是环境写操作。只有获准管理的专用实例才能操作；源文“删除容器旧数据不丢”不能充当随意删除共享实例的保证。
- `set-socket-port.sh` 附件会校验端口、修改环境文件并 force-recreate 容器，不是只读诊断脚本；不要为页面测试自动执行它。

## 跨环境/企业复制

- 两篇源文均明确：**不要往正式环境拷贝数据**。即使用户需要测试数据，也不能直接反转示例的源/目标域名。
- 跨企业项目存档入口和跨环境 API 脚本是不同方法。先核对实际资源类型、源/目标企业、目标文件夹、权限和数据可复制范围，再决定是否需要这一步。
- 原文表复制代码只处理项目中的表；不能推断同时复制故事板、图表或全部数据源。FVS 另有创建报告再保存配置的示例。
- FVS 文档结果截图明确出现“图表丢失”：复制了看板配置不证明图表/数据源依赖已迁移。准备后分别检查配置、依赖绑定、数据加载和可交互状态。
- 不执行文档中带固定资源 ID 或 Bearer 令牌的示例，不把旧 Token 视为可复用凭据。需要时从当前获准会话取得最小范围访问，并在内存中使用。
- 写入超时/结果不明时先查询目标是否已创建，再决定是否重试，避免重复文件。清理只处理本次创建、归属明确且无需保留的测试资产。

## 指标树历史版本前置

以下为用户在2026-10-29确认的规则，适用于指标树历史版本的夹具准备：

- 新建指标树会立即正式保存为V1。空树尚无指标，不代表尚未生成V1。
- 创建后5秒内迅速添加指标并正式保存，会合并到创建时的V1，从而得到含指标的V1。此处“5秒防抖”是版本合并窗口，不能理解为等待5秒才创建V1。
- 也可直接创建带指标的指标树副本，副本初始V1即含复制的指标配置。复制完成后核验副本的V1和配置，不把源树的历史列表视作副本历史。
- 需要“V1只含销售额”等基线时，优先复制已准备好该配置的树；使用快速新建方式时，记录创建和保存的实际时间、版本号及配置，确认确实合并为V1。
- 需要普通正式保存新增一个版本时，与前次正式保存间隔超过5秒，并以保存结果、历史版本号和操作时间核验。“后续编辑不覆盖初始快照”的断言须区分5秒内合并与窗口外新增版本。
- 带指标的副本可解决V1配置前置，不能替代“新建空树尚未编辑”或“升级前无历史存量树”的场景。

## 常见准备阻塞的报告方式

记录“目标场景 → 缺少什么 → 已完成什么 → 需要谁完成哪一步”，继续不依赖它的检查。例如缺白名单不阻断现有成员列表观察；缺 MongoDB 权限不阻断埋点发送侧检查；缺专用本地宝不授权重启公共实例。
