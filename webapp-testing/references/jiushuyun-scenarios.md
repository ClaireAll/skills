# 九数云场景覆盖与业务语义

按本次已授权场景选择关联维度；本文件提供选项，不自动扩大测试范围，也不代替当前产品验收标准。来源见 [测试计划场景覆盖关键词与业务术语](toolbox-sources.md)。

## 关键词对应的验证维度

| 触发点 | 相关检查 |
| --- | --- |
| 用户/成员 | 待加入、已离职、已停用、不可见、已删除；交接；改名、长名称；企微显示名；查看者/编辑者/管理员/超管及集成系统管理员/创建者 |
| 名称、标题、描述、备注 | 空值、重名、最大长度；以实际需求确定限制及提示，不从经验编一个长度 |
| 列表 | 空列表、分页和页大小、固定高度/滚动；列表总数与可见数据 |
| 搜索/筛选 | 无匹配、匹配规则、清空恢复、筛选后可操作范围；不能把通讯录不可见创建者当必然应命中 |
| 导出 | 当前角色与安全管理导出开关的组合；有权限时校验下载内容/范围，受限时校验入口与反馈；不得擅自改变共享开关 |
| 实时交互 | 明确自动刷新还是手动刷新；多标签/用户的独立会话；恢复后补最新数据及后续持续更新 |
| 手机号 | 集成方式是否提供手机号；缺值不直接判失败，按适用协议/需求判断 |
| 时间/日期 | 融合版时区、地区、每周第一天及跨日/周边界；UTC 埋点时间与页面本地时间分别记录 |
| 企业权益 | 免费/付费版本、试用/已到期、行数/内存/容量限制；只覆盖任务要求的版本 |
| 并发/升级兼容 | 关键词文档未给出具体规则；从当前需求补足触发、冲突处理及数据保留预期，不编造结论 |

## 业务术语决定观测对象

- 镜像：文档列出表、仪表板、故事板、FVS、计算模型的镜像，配置/数据跟随源文件。副本或存档不是镜像，不把独立副本的行为当镜像预期。
- 存档：保留当前数据为 Excel，不自动跟随源更新；手动更新存档 Excel 的能力另行核对。
- 数据准备/数据目录：管理入口与下游使用权限不同；表或仪表板的“配置权限”可能影响不同用户看到的行数据。
- 分析表：区分主线、左右合并/高级图表产生的分支、分组内步骤及组外独立步骤。结果/透视图表在最后阶段，中间图表位于中间步骤；高级模式拆分图表可在分支加步骤。
- 组合步骤：文档列出占比、排名、拆分到列。不要把组内步骤与组合步骤视为同一个概念。
- 融合版“系统数据”对应简道云数据源；系统字段包含成员、成员多选、部门、部门多选等 ID 类，以及定位、地址、手机等非 ID 类。复合日期字段截图列出年季度、年月、年周数、年星期、月日。涉及这些类型时使用实际字段样本。
- CPP 与 MPP 是计算架构，不是“两个域名”。当前计算需求确实要求双架构时分别留实际路由证据，不能仅切域名就声称覆盖两种架构。
- 源数据容量：文档说明数据源表未加入项目不计入，重复加入同一表只计一次；具体权益和版本口径需回查当前规则。
- 仪表板懒加载：首屏不可见组件需进入视口后加载。滚动前没 DOM/数据不等于组件丢失。
- Banner 区分付费/到期、运营推送、模板应用后缺匹配数据源引导。不同成因的文案和关闭行为不能互相替代。

## AI 功能

仅在任务涉及 AI 时选取适用项：

1. 意图与正确性：提取指标、时间和筛选条件；输出逻辑一致；搜索的召回和精度用已知样本核对。
2. 数据不变量：美化前后的指标总和、过滤条件、字段绑定不应被无意改写；不能只看配色好看。
3. 鲁棒性：错字、口语、空白、长输入、复杂仪表板；字段不存在时不编造数据或链接。
4. 权限与注入：AI 沿用当前用户数据权限；在获准安全测试范围内检查绕过指令，不读取或传播真实秘密。
5. 稳定性与体验：记录首字/首动作和完成时间；用相同输入重复采样观察波动，不能要求非确定性输出逐字相等。文档中的“3 秒”“1000 组件”等是示例，未经确认不设为统一门槛，也不自动发起压测。
6. 解释与闭环：有需求时验证来源/匹配原因、撤销/重新生成、反馈记录；不因方法文档提到就认定每个 AI 功能必须有同样按钮。
