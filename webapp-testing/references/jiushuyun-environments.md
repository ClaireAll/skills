# 九数云环境、身份与版本

来源核对：2026-10-26；原文及读取边界见 [来源索引](toolbox-sources.md)。只在九数云/数据分析页面测试时使用，入口和支持情况在执行当次重新确认。

## 测试前先确认环境指纹

记录目标完整域名、dev/test/work 等环境、企业类型、集成方式、企业 ID、当前用户/角色、相关版本及白名单；计算相关场景记录实际 CPP/MPP 架构，日期场景记录租户时区。不能只凭站点外观或域名推断企业类型：独立版迁成融合版后可能继续使用原域名。

- 不同域名的企业、模板和配置可能隔离。在另一个域名能看见企业，不证明目标环境数据丢失，也不能替代目标环境测试结果。
- 运营端后台管理平台配置、版本、白名单、模板等，后台角色不等于企业内资源权限。超级管理员也不等于对所有数据有权限。
- 测试账号和数据源连接信息按当次需要从受限原文读取；不把共享账号密码、数据库密码、密钥或截图中的令牌固化到 Skill。

## 集成模式与身份

- 集成企业的创建者可能在平台通讯录不可见；查不到创建者先核对身份/入口及当前需求，不直接报成员搜索缺陷。
- 文档提醒独立版钉钉 test 首次使用先扫码登录并绑定手机号，再从工作台进入；独享版 CP 在该文档中列为从工作台进入、无扫码登录。先核对适用分支，不把所有集成方式统一为一个流程。
- ISV 与自建应用可能在同一第三方组织下，但绑定的应用和企业不同；组织名称一致不代表身份/租户一致。
- 文档列出短信通知、飞书卡片/回填、酷应用等在不同部署下的支持差异；只检查当前任务涉及的能力。仅安装简道云应用并开启九数云模块不等于自动化卡片通道已就绪。
- 二维码失效、未加入第三方组织或缺应用权限时，保留目标和待完成步骤，由用户完成登录/加入/授权，不自动重装应用。

## 只读确认标识

在已授权的目标页面、且对应对象实际存在时，可读取：

```javascript
BI.system.currentCorpId
BI.personal.userId
```

企业信息页可核对企业 ID，成员接口中的 ID 需区分用户 ID 与成员 ID。简道云个人设置的用户 ID 与九数云企业 ID 不能混用。优先使用页面/运行时明确暴露的值；必须解析 JWT 时仅本地解码必要字段，不把完整令牌送到外部解码网站。解码不等于签名或权限验证。

## 版本、试用与白名单的准备边界

- 融合版/国际版文档通过 SA 的“一体化订单创建 → 订单管理提前开版本”配置；付费到期和试用到期在不同调整页面。
- 独享版通过 PaaS license 与 CS 授权管理配置，可能影响同域名全部租户。页面测试缺功能时，先报告影响范围，不能为继续测试自行改 license。
- 平台模块线索：`analytics_beta` 为数据分析入口；`extended_locale` 涉及小语种和时区；地区、每周第一天另有配置。相关白名单和用户/企业级配置不同。
- 数据分析复杂表等功能通常在运营端按企业 ID 配置；模板发布白名单使用用户 ID。文档有例外，按当前功能的源文核对。
- 文档包含低额支付、手动支付接口、直接改库示例：这些都可能改变订单/权益，即使 HTTP 方法是 GET 也不是只读测试。没有对应授权时不执行。
- 获准准备测试版本时，记录原值、作用域、目标值和恢复办法，再确认目标页上的生效结果。不能只凭后台保存成功判定前置条件已满足。
