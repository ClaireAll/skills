# A股、国内ETF与公募基金研究

## 已确认的使用范围

支持已有持仓诊断与主动筛选；同时支持几天以内的短线、几周到几个月的波段。只做研究和条件式建议，不连接券商账户、不下单、不承诺收益。用户指定一种任务或周期时，只做指定部分；同时分析两个周期时分开输出，不能因短线判断失败而改称长期持有。

## 先确认会改变结论的信息

- 明确代码、名称、市场与产品类别；同样的六位代码可能是股票或基金，不能只凭代码长度判断。
- 持仓诊断需要用户提供的代码、仓位或金额；成本用于解释盈亏，不是必须回本的估值依据。只有给出具体调仓比例或金额时，才必须了解总投资规模、可用现金、资金用途、持有期限及能接受的亏损；信息不足先给观察结论，不猜风险承受能力。
- 主动筛选先明确候选池、周期和限制。没有持仓也可以研究候选，但不要把过去收益排行直接当作买入清单。
- 不需要账号、密码、身份证、验证码或交易权限。向公开数据源发送代码等必要参数，不发送用户的持仓金额或账户截图。

## 数据与证据

1. 用 AKShare 获取最窄的数据集，记录原始数据源、获取时间、行情/净值日期、单位、币种、周期与复权口径。时间按北京时间说明；运行日期不是数据日期。
2. 公告、财报、分红、基金费率与交易限制回查交易所、上市公司或基金管理人的原文；数据聚合站不是公告原始出处。
3. 需要市场讨论时使用 `agent-reach` 的已接通渠道。保留原始链接、发布时间和论点，区分传闻、观点与可核实事实；转载不能冒充多个独立来源。没有渠道或登录态就说明缺口，不捏造“市场情绪”。
4. 空表、缺字段、缺交易日、过期缓存、源间冲突都要披露。优先有限重试或同类数据源，不用不同时点的数据拼出实时结果，也不以旧数据悄悄替代失败的新数据。
5. 基金披露持仓注明报告期，不能当作实时持仓。净值、分红、拆分与复权需对应；ETF 市价、IOPV 和净值比较必须说明各自的时间，不把溢价或拆分跳变当作真实投资收益。
6. 判断盘中报价可用于即时观察前，核实源明确标为实时、报价带当日时分秒、处于对应交易时段且无延迟标记；同时展示报价时刻与采集时刻。只有日期、无法核实源的延迟、跨时段或明显陈旧的报价均降为历史/条件式分析，不据此声称即时触发。日线对照最近已结束交易日，基金净值对照产品披露日，不把“抓取成功”当作“数据最新”。

## 按周期判断

| 模式 | 必须关注 | 数据不足时 |
| --- | --- | --- |
| 短线：几天以内 | 消息原始出处和时效、量价、成交与流动性、ETF折溢价、持仓集中度，以及具体标的当前交易规则和费用 | 缺少有效最新行情时，只给历史复盘或下一交易时段的条件式观察，不报即时进出价格，不声称已经触发 |
| 波段：几周到几个月 | 财务和估值、行业与政策变化、趋势与回撤、组合重复暴露、基金经理/规模/费率，以及再平衡成本 | 缺少关键财报或基金披露时，说明哪项结论无法成立；证据不足可建议暂不调整 |

场外基金不提供股票式盘中成交信号；需要短期申赎判断时先核实产品的净值确认、赎回费、到账和持有期规则。不同股票、ETF、基金的交易机制不能互相套用。

## 输出约定

先用一句话回答用户的问题，再提供与任务相称的证据，不固定凑推荐数量。结论可以是观望或不操作。

每个持仓或候选至少包含：

| 项目 | 内容 |
| --- | --- |
| 标的与角色 | 代码、名称、产品类别；已有持仓或候选；短线或波段 |
| 当前倾向 | 观察、持有、条件式分批买入、减仓或退出，并说明是否缺少个人风险信息 |
| 依据与反证 | 关键来源、数据截止时间、事实与推测分开，列出相反证据 |
| 触发条件 | 什么可观察变化发生后才考虑操作；未发生就不当作已触发 |
| 失效与退出 | 哪些变化推翻判断，何时重新评估；不随行情变化事后改写原条件 |
| 风险与成本 | 可能亏损、集中和流动性风险、费用；缺失数据影响哪条结论 |

不凭语言模型感觉编造上涨概率、胜率或目标收益。引用回测时标明样本期、样本外检验、基准、交易成本与前视/幸存者偏差；回测不是收益承诺。对具体仓位和买卖金额的建议必须结合用户提供的财务与风险约束，不自动套用固定百分比。
