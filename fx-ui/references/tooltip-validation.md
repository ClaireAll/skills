# Tooltip、Title 与校验规范

## 适用边界

- `Title` 指浏览器原生 `title` 属性；`Tooltip` 和 `Pop` 是独立交互模式，不能混用规则。
- 截断文本、Select/Input 回填值的完整内容使用原生 Title。
- 按钮名称、禁用原因、错误原因、文本或列表对象说明使用 Tooltip。
- `icon-help` 的富文本、链接或图片说明使用 Pop。
- 文档中的待定项只能作为待确认点，不能直接判定违规。

## Title

- 列表文本或 Select/Input 回填值被截断时，`title` 必须承载未截断的完整文本。
- 组件默认渲染已经把完整 `title` 透传到可悬浮 DOM 时，不要求调用处重复传入。
- 不能仅凭调用处没有 `title`、存在 `truncate` 类名或使用了自定义组件判断违规；需要查看组件实现或运行时 DOM。
- Title 只解决完整文本查看，不替代禁用原因或错误原因 Tooltip。

## Tooltip 延时与定位

- 仅列表类 Tooltip 在 hover `0.5s` 后显示。
- 按钮、普通文本、Input/Select 校验、Help Pop 和其他非列表悬浮提示默认为 `0.1s`。
- 不使用 `0s` 延时；组件默认已经是 `0.1s` 时，不要求调用处重复配置。
- Tooltip 不占布局；默认在触发对象下方，空间不足时翻转到上方并处理碰撞。
- 按规范使用触发点左下约 `4px` 的间距，优先复用已有 token 或组件配置。
- 鼠标离开触发热区和 Tooltip 后消失；允许进入 Tooltip 本身。

## 样式判定顺序

先判断触发对象，再判断状态。禁用不等于错误。

| 触发对象 | 默认态与禁用态 | 报错态 |
| --- | --- | --- |
| 按钮 | 深色、有三角箭头，默认位于下方 | 错误色、有三角箭头，默认位于下方 |
| 文本、列表 | 深色、无箭头，与文本左对齐并位于下方 | 错误色、无箭头，默认锚在触发对象中点的左下 |

同一对象同时具有禁用和报错语义且需求未说明优先级时，标记待确认。

## 校验与标红

- 校验 Tooltip 默认展示；错误 Tooltip 在悬浮时展示；同一容器不要同时触发多个 Tooltip 风格。
- 普通 Input/Select 的错误使用红色外框，文字保持黑色；文本类提示跟随外框左下且无箭头。
- 非表单或局促容器中的 Input，只有在来源规则适用时才检查实时校验、focus 显示、blur 隐藏和失焦恢复上一次合法值。
- 胶囊类容器只标红具体错误元素；文本类 Tooltip 跟随内容左下并按该容器规则显示箭头，按钮类 Tooltip 跟随内容中下并显示箭头。
- 类 Input 容器按实际报错元素标红；不要把某一专项场景的提示时机扩张为所有表单。

## 审查证据

至少分别检查：

- 截断 + 正常态：完整 Title 是否实际落到可悬浮 DOM。
- 截断 + 禁用态：禁用原因 Tooltip 是否可触达，是否误用错误色。
- 截断 + 错误态：错误 Tooltip 是否可触达，是否错误叠加 Title。
- disabled + hover：对象类型、延时、颜色、箭头、锚点是否匹配。
- error + focus/hover：标红对象、提示时机、位置和箭头是否匹配。
- invalid + blur：仅在适用场景检查是否恢复上一次合法值。
- 视口碰撞：下方空间不足时内容是否可访问。
