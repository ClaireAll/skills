# 说明图标、Pop 尺寸与 Loading

## 说明图标

- 解释或帮助说明使用灰色图标，优先复用设计系统的中性 icon token。
- 不把错误、警告、成功等业务状态图标套用本规则。
- 图标作为 Tooltip 或 Pop 触发器时，颜色调整不能破坏 hover、点击或键盘可触达性。

## Pop 尺寸

- Pop 宽度需要真实边界：可以由自身 `width`、`min-width`、`max-width` 提供，也可以由不会继续横向扩张的固定宽度内容形成等价边界。
- 不能仅因 Pop 没有显式宽度属性就判违规；先判断内容是否会继续横向增长。
- 无法从代码、组件 API 或运行时确认横向边界时，标记待确认。
- 只有内容会撑高 Pop 时，才检查视口可用高度、业务最大高度和 overflow。内容高度固定时跳过这些检查。
- 内容撑高时，弹层不能超出当前视口可用范围；超过最大高度必须能够滚动访问全部内容。`600px` 仅是建议上限，不是绝对阈值。

## Loading

- 使用 FD `Spin` 的 `roll` 效果，或仓库对它的统一封装。
- 不为同类加载反馈另造视觉不一致的 Spinner。
- 审查时确认实际渲染效果，不能只凭组件名或变量名判断。
