# 前端本地搜索规范

## 适用边界

- 只审查前端本地过滤。匹配结果由远端接口决定的搜索直接跳过，不把后端能力标为前端违规或待确认。
- 同一入口同时包含远端搜索和本地过滤时，只审查本地过滤步骤。
- “大小写不敏感”是用户可见行为要求；由组件库还是业务组件实现属于实现证据问题。

## 匹配行为

- 本地数据在输入时实时过滤，不额外等待 blur 或 Enter。
- 支持中文直接匹配、英文字母忽略大小写、中文全拼和拼音首字母。
- 命中项展示高亮；拼音或首字母命中时，高亮对应的中文字符。
- 过滤和高亮使用同一展示文本与同一匹配语义，不能出现命中但无高亮，或高亮项未被过滤保留。
- 对象或 ReactNode 先提取稳定可见文本，不能隐式转成 `[object Object]`。

## 状态保持

根据入口现有设计检查：

- 搜索、清空和重新打开后，已选值是否保留并可提交。
- 禁用项、禁用原因、错误标红、缺失字段、权限和图标是否保持。
- 全选/反选是否只作用于当前可见过滤结果。
- 分页、快捷选择、Enter 新增等既有能力是否保留。
- 弹层式 Select 或树选择器关闭即重置时，关闭后清空关键字；不要扩张到常驻搜索框。

## 组件复用

- 优先复用 `@fd/fine-design-biz` 的 `isMatchByKeyword`、`HighLightText` 或仓库等价统一封装。
- 不新增只支持 `includes`、手工转小写或只支持字面高亮的分叉实现。
- 过滤文本与高亮展示文本必须一致；明确选择 `label`、`name`、`title` 或实际展示字段。
- 组件已有过滤或渲染入口时，不能绕过已选、禁用、错误或权限逻辑。

无法确认远端/本地边界或统一封装行为时，标记待确认，不直接判违规。
